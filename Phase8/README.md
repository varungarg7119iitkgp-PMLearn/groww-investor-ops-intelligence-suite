# Phase 8 — RAG Infrastructure & Smart-Sync KB

> **Goal:** Replace the mock chat responses in the Investor Terminal with grounded, citation-bearing answers backed by a TF-IDF index over the 100 fund chunks seeded in Phase 7, generated by Google Gemini with strict facts-only / no-advice guardrails.

## Deliverables

1. **TF-IDF retriever** — `src/tools/rag-retriever.ts`
   - Custom in-process TF-IDF cosine-similarity index over Supabase `fund_chunks`
   - `retrieveTopK(query, k=8, fundFilter?)` — sorted by relevance
   - Lazy-built singleton with manual refresh hook for tests
2. **Fund identifier** — `src/lib/fund-identifier.ts`
   - Substring + keyword_aliases matching against the 20-fund universe
3. **Fee Explainer** — `src/tools/fee-explainer.ts`
   - Detects fee-related queries (expense_ratio / exit_load / tcs / brokerage / account_maintenance)
   - Returns `≤6` bullets + exactly 2 source URLs + `last_checked` date
4. **Gemini client** — `src/lib/gemini.ts`
   - Thin wrapper around `@google/generative-ai`
   - `generateContent(prompt, opts)` with timeout, retry, structured JSON parsing
5. **Smart-Sync prompt** — `src/lib/prompts.ts`
   - Strict 6-bullet enforcement
   - Mandatory citations (`[Source: <fund_name>]`)
   - Facts-only, no advice, no future projections
6. **Compliance v1** — `src/lib/compliance.ts`
   - 20+ no-advice phrase regex bank
   - Out-of-scope handler (fund not in 20-universe)
   - PII detection hook (full redaction lands in Phase 9)
7. **Chat API route** — `src/app/api/chat/route.ts`
   - `POST { query } → { answer, bullets[6], citations[≥1], lastUpdated, complianceFlag }`
   - Workflow: input-guard → identify funds → retrieve top-k chunks → fee explainer (if fee query) → Gemini → output-guard → respond
8. **ChatTerminal wiring** — `src/components/investor-terminal/InvestorTerminal.tsx`
   - Replace the mock setTimeout response with real `/api/chat` fetch
   - Surface citations + lastUpdated timestamp
   - Loading orb (THINKING) during request

## AI Eval Gate — RAG Accuracy (First Pass)

Suite: `rag_accuracy` (Phase 8)

| # | Query | Expected sources | Pass criteria |
|---|---|---|---|
| 1 | Expense ratio of HDFC Silver ETF vs Axis Silver | HDFC + AXIS commodity fees chunks | Both funds cited, no fabrication |
| 2 | Exit load for ELSS / equity funds — why was I charged after 3 years? | ELSS/equity fees chunk + fee_scenarios(exit_load) | Factsheet % + fee logic merged |
| 3 | Compare 3-year returns of one Debt fund and one Equity fund | 1 debt perf chunk + 1 equity perf chunk | Real numbers, no projection |
| 4 | What is TCS on MFs + funds with highest expense ratio? | fee_scenarios(tcs) + multiple fund fees chunks | TCS explainer + ranking |
| 5 | Risk level of commodity funds vs hybrid funds | Commodity + Hybrid risk chunks | Riskometer cited, no advice |

**Metrics (LLM-judge):**
- **Faithfulness** ≥ 0.7 (every claim traceable to a cited chunk)
- **Relevance** ≥ 0.7 (retrieved chunks pertinent to query)

Pass criterion: **Aggregate Faithfulness ≥ 0.7 AND Relevance ≥ 0.7**.
